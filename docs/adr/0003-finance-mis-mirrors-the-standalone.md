# The ARR Dashboard mirrors the standalone Finance MIS app

Finance MIS was ported into the Finance perspective while the standalone app stays in daily use, so the finance team moves between the two and compares them. The first port kept the figures and the addresses but rebuilt the screens in One's plainer style, and finance asked for the standalone's view back and for the screens to stop being black and white. Shown three prototypes — the standalone's chrome reproduced in One's tokens, the same anatomy in Oxygen's default chrome, and the standalone's chrome on Oxygen surfaces — they chose the faithful one, and then asked for the tables to match, which was done by measuring the standalone's live tables rather than reading its stylesheets. We decided the ARR Dashboard reproduces the standalone's anatomy (Period row, filter card, seven tabs, Unit pills, one grid card), its chrome and its measured table geometry, expressed through One's theme tokens, with the few values Oxygen cannot express (slate text, slate bands, the source's radii and shadows) held in one look-token module. What stays One's is the shell (rail, eyebrow, h1, dark mode), Retry on failure, the WideTableNotice, Excel as the typed-number export, and sign-only negatives, which the standalone shares.

Considered and rejected: Oxygen's house style for these screens (two faces for one report during the overlap, and the first port had already shown finance would not accept it); cloning the standalone's libraries (AG Grid and MUI X charts) for identical rendering (two more grid and chart libraries in the workspace, and they fight dark mode and the accessibility overrides); reproducing the standalone's accidents (its blue row hover and grand-total gradient are stylesheet rules that never apply to the rendered grid, so One keeps a primary-tinted hover and a plain bold total).

Consequences: literals Oxygen has no token for live in one module, with the standalone value each stands in for beside it, until Oxygen offers a slate step; ARR Analysis is not covered, because the standalone's Analysis changed upstream after the inventory and needs its own spec; the prototype branch `prototype/mis-look` is the primary source for the geometry and is never merged.
